This project is named as বাজার দর (BazarDor)

Its a website where users can easily check the latest prices of daily essential products in Bangladesh.

Technologies that are used in this project are Next.js, React, TypeScript, Tailwind CSS, DaisyUI, Better Auth, React Toastify.

5 key features are:

1. View daily prices of essential products.
2. Browse products by category.
3. See price increases and decreases.
4. Sign up and sign in to an account ,also can use google and github
5. Responsive design for mobile, tablet, and desktop.
